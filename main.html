Arena rules & integrator appendix

Operational gates for humans shipping ChickCombo adjacent tools.

  1. Gate A: hatch only when species catalog entry is non-zero on-chain.
  2. Gate B: rename collisions are allowed off-chain but discouraged for exports.
  3. Gate C: spar tickets reference attacker/defender ids; never reuse settled ids.
  4. Gate D: league pot accounting uses uint128 — watch sweep bounds in production.
  5. Gate E: donate path is nonReentrant; do not wrap with untrusted hooks.
  6. Gate F: ownership handoff is two-step; verify pending owner before accept.
  7. Gate G: pause is owner-only; publish incident runbooks referencing event CC_PauseSet.
  8. Gate H: ADDRESS_A may grant bonus grain — treat as privileged oracle, not user.
  9. Gate I: immutables are constructor-fixed; rotate by redeploying with new bytecode.
  10. Gate J: receive/fallback reject ETH — users must use donateLeague for value.
  11. Gate K: mint paths are nonReentrant to guard against weird ERC777 reentry (none here).
  12. Gate L: training picks mix SALT_A with prevrandao — casual entropy only.
  13. Gate M: forage mixes SALT_B with block number surrogate in Python, not on-chain.
  14. Gate N: evolve checks duplicate evolution via bool flag — cannot re-evolve.
  15. Gate O: move slots bounded to CC_MOVE_SLOTS — UI should clamp before send.
  16. Gate P: cooldown errors include timestamps — surface them in wallets.
  17. Gate Q: type chart is pure function — mirror in multiple clients for consensus.
  18. Gate R: streak mapping resets on loss — reflect in UI badges.
  19. Gate S: xp curve divisor 220 matches UI syncLevel — keep constants aligned.
  20. Gate T: level cap 72 is public constant — display in marketing footers.

  27. Gate Z: ADDRESS_B/C reserved for future league modules — do not hardwire behavior yet.
  28. Appendix 1: browser sim uses PRNG; chain uses prevrandao — expect divergence.
  29. Appendix 2: export CSV quoting uses JSON.stringify on nicknames for commas safety.
